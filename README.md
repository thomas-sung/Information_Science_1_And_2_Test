## 📖 系統操作與使用指南

### 1. 👤 考生身分登入與成績記錄
- 初次進入系統或點擊右上角 **「👤 訪客 (點擊登入)」**，可填寫您的 **姓名** 與 **班級 / 座號 / 學號**。
- 登入後，您每一次測驗的成績單、答對率、耗時、歷史紀錄與錯題本都會標記為您的名字，方便追蹤學習成長曲線。

### 2. ⚙️ 三大測驗模式任你選
進入首頁後，您可以依當前複習階段選擇最適合的模式：
- **🚀 模擬考試模式（限時實戰）**：
  - 模擬正式統測情境，提供倒數計時器（可選 15 / 30 / 60 / 80 分鐘）。
  - 作答完畢交卷後立即結算成績（百分制）、答對題數、掌握度等第分析（精熟 / 良好 / 及格 / 待加強）與各單元雷達診斷。
- **📝 練習刷題模式（即時看解析）**：
  - 無作答時間壓力，作答後或點擊「💡 展開本題詳解」，即可當場查看詳細推導步驟與核心考點，適合日常平時觀念補強。
- **🎯 錯題本專攻（弱點消滅）**：
  - 系統自動收集您在歷次測驗中**答錯或漏答**的題目，考前可針對個人薄弱盲點進行專項集中重練。

### 3. 🎯 靈活選擇考卷範圍與題數
- **依年度全卷測驗**：可直接挑戰 **114 最新衝刺卷**、**113 統測卷**、**112 統測卷**、**111 統測卷**、**110 統測卷** 或 **109 統測卷**（每年各 50 題）。
- **依學校模擬考進度**：
  - **第 1 次模考範圍**：基電直流 / 邏輯閘布林代數 / C 語言基礎
  - **第 2 次模考範圍**：暫態二極體 / 組合邏輯 / 迴圈陣列
  - **第 3 次模考範圍**：交流電路 BJT / 循序邏輯 / 指標函式
  - **第 4 次模考範圍**：諧振 OPA / 遞迴結構體 / 通訊中斷
- **題數彈性自選**：支援 10 題（快速隨堂考）、25 題（統測單科標準題數）、50 題（全卷試卷）或全庫地毯式刷題。

### 4. 📚 免測驗隨選「題庫詳解總覽」
如果您考前想直接閱讀觀念與詳解，不想花時間一題一題做答：
- 點擊頂部導航列的 **「📚 題庫詳解總覽」** 或首頁的 **「📖 瀏覽全科題庫與解析」**。
- **多維度篩選**：可隨時按 **年度（109～114年）**、**考科（專一／專二）**、**單元分類** 與 **模考範圍** 快速過濾。
- **關鍵字全文搜尋**：輸入如「戴維寧」、「OPA」、「卡諾圖」、「指標」、「遞迴」、「中斷」，立即找出所有相關試題！
- **完整解答一目了然**：每題均清楚標註綠色 **`✓ 正確答案`**、電路示意圖與完整的解題計算步驟。

### 5. 🎲 換組好算數字（告別醜數字）
- 在瀏覽計算題時，只要看到右上角有 **「🎲 換組好算數字」** 按鈕，點擊一下即可立即更換一組**整除、漂亮好算**的數值，並同步展示新的公式代入與計算推導步驟，幫助您徹底搞懂物理觀念而不是被繁複小數運算卡住！

### 6. 📊 歷次成績與跨裝置資料備份
- 點擊頂部 **「📊 歷次成績」**，可查看過往所有測驗的時間、分數與耗時。
- **資料安全與備份**：成績資料儲存在您的瀏覽器中，不會上傳外部伺服器，注重隱私。
- **匯出 / 匯入資料**：點擊「💾 匯出資料 (JSON)」可將做題紀錄下載備份；換新電腦或手機時，點擊「📥 匯入資料」即可無縫還原個人歷史成績與錯題本！

### 7. 🌙 深色 / 淺色模式一鍵切換
- 點擊頂部右上角的 **🌙 / ☀️** 按鈕，即可自由切換護眼深色主題或清新淺色主題，夜間挑燈夜戰不傷眼。

## 💡 統測資電類考前衝刺技巧

1. **基本電學**：節點電壓法、戴維寧等效、交流阻抗三角形與最大功率轉移是兵家必爭之地，公式務必熟記。
2. **電子學**：OPA 虛接地概念是送分題；BJT 的三種組態特性（CE、CB、CC）以及直流工作點 $I_B, I_C, V_{CE}$ 計算要多加演練。
3. **數位邏輯**：卡諾圖圈選要圈最大相鄰項（注意 4 角相鄰與無關項 $X$ 的運用），JK 正反器真值表與計數器模數計算必須秒殺。
4. **程式設計**：指標算術 `*(p+i)`、字串以 `\0` 結尾、`switch-case` 缺少 `break` 的穿透現象是統測試題的經典陷阱。
5. **微處理機**：8051 五大中斷向量入口位址、定址模式區分（立即、直接、間接 `@R0`）與內部 RAM 128 Bytes 分區每年必考。
